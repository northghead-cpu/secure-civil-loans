# 🚀 Secure Edge Functions Deployment Guide\n\nThis guide walks you through deploying the three new Supabase Edge Functions that handle sensitive operations (CRB checks, payroll integrations, and admin settings).\n\n## Table of Contents\n\n1. [Prerequisites](#prerequisites)\n2. [Automated Deployment](#automated-deployment)\n3. [Manual Deployment](#manual-deployment)\n4. [Environment Variables](#environment-variables)\n5. [Verification](#verification)\n6. [Troubleshooting](#troubleshooting)\n\n---\n\n## Prerequisites\n\n### Required\n\n- **Supabase CLI** installed locally\n- **Logged into Supabase**: `supabase login`\n- **Project linked**: `supabase link --project-ref <YOUR_PROJECT_REF>`\n- **Node.js 18+** (for Deno compatibility)\n\n### Installation\n\n```bash\n# Install Supabase CLI globally\nnpm install -g supabase\n\n# Verify installation\nsupabase --version\n\n# Login to Supabase (opens browser)\nsupabase login\n\n# Link your project\nsupabase link --project-ref abc123xyz\n```\n\nFind your project reference at [https://supabase.com/dashboard/projects](https://supabase.com/dashboard/projects).\n\n---\n\n## Automated Deployment\n\n### Step 1: Deploy All Edge Functions\n\n```bash\n# Make the script executable\nchmod +x scripts/deploy-edge-functions.sh\n\n# Run the deployment script\n./scripts/deploy-edge-functions.sh\n```\n\nThis script will:\n✅ Verify Supabase CLI is installed\n✅ Deploy `crb-check` function\n✅ Deploy `payroll-integration` function\n✅ Deploy `admin-settings` function\n✅ Provide deployment status\n\n### Step 2: Set Environment Variables\n\n```bash\n# Make the script executable\nchmod +x scripts/set-env-vars.sh\n\n# Run the environment variables setup script\n./scripts/set-env-vars.sh\n```\n\nThe script will prompt you to enter:\n- **CRB_API_KEY**: Your TransUnion CRB API key\n- **PAYROLL_API_KEY**: Your payroll provider API key\n\nThese secrets are stored encrypted in Supabase and NOT committed to version control.\n\n---\n\n## Manual Deployment\n\n### Option A: Deploy Functions One by One\n\n```bash\n# Deploy crb-check\nsupabase functions deploy crb-check --no-verify\n\n# Deploy payroll-integration\nsupabase functions deploy payroll-integration --no-verify\n\n# Deploy admin-settings\nsupabase functions deploy admin-settings --no-verify\n```\n\n### Option B: Set Environment Variables Manually\n\n```bash\n# Get your project reference\nPROJECT_REF=$(supabase projects list --json | jq -r '.[0].id')\n\n# Set CRB_API_KEY\nsupabase secrets set CRB_API_KEY=\"your_transunion_api_key\" --project-ref=\"$PROJECT_REF\"\n\n# Set PAYROLL_API_KEY\nsupabase secrets set PAYROLL_API_KEY=\"your_payroll_api_key\" --project-ref=\"$PROJECT_REF\"\n```\n\n### Option C: Via Supabase Dashboard\n\n1. Go to [https://supabase.com/dashboard](https://supabase.com/dashboard)\n2. Select your project\n3. Navigate to **Edge Functions** → **Settings**\n4. Add secrets:\n   - `CRB_API_KEY`\n   - `PAYROLL_API_KEY`\n\n---\n\n## Environment Variables\n\n### Required Secrets\n\n| Name | Description | Example |\n|------|-------------|----------|\n| `CRB_API_KEY` | TransUnion Credit Reference Bureau API key | `Bearer sk_live_xyz...` |\n| `PAYROLL_API_KEY` | Payroll provider API key (e.g., Zambia Civil Service) | `sk_api_xyz...` |\n\n### Accessing Secrets in Functions\n\nWithin Edge Functions, secrets are accessed via:\n\n```typescript\nconst crbApiKey = Deno.env.get(\"CRB_API_KEY\");\nconst payrollApiKey = Deno.env.get(\"PAYROLL_API_KEY\");\n```\n\n### Security Best Practices\n\n✅ **DO:**\n- Store secrets in Supabase secrets manager\n- Use environment variables (not hardcoded)\n- Rotate secrets regularly\n- Limit secret access to only required functions\n- Audit secret usage via logs\n\n❌ **DON'T:**\n- Commit secrets to version control\n- Log secret values\n- Share secrets via email/chat\n- Use the same secret for multiple services\n\n---\n\n## Verification\n\n### 1. Check Deployment Status\n\n```bash\n# List all Edge Functions in your project\nsupabase functions list\n```\n\nExpected output:\n```\nName                      Status      Version\ncrb-check                 Active      v1\npayroll-integration       Active      v1\nadmin-settings            Active      v1\n```\n\n### 2. View Function Logs\n\n```bash\n# Stream logs from crb-check function (real-time)\nsupabase functions list --project-ref=<REF>\n\n# Or in Supabase Dashboard:\n# Edge Functions → Function Name → Logs\n```\n\n### 3. Test Function Invocation\n\nFrom your React frontend:\n\n```typescript\nimport { edgeFunctionService } from \"@/services/edgeFunctionService\";\n\n// Test CRB check\nconst result = await edgeFunctionService.checkCRB({\n  nrc_number: \"123456789\",\n  full_name: \"John Doe\"\n});\nconsole.log(\"CRB Result:\", result);\n```\n\n### 4. View Secrets (Values Hidden)\n\n```bash\n# List all secrets (values are redacted)\nsupabase secrets list\n```\n\nOutput shows keys but hides values:\n```\nName               Digest\nCRB_API_KEY       ****...****\nPAYROLL_API_KEY   ****...****\n```\n\n---\n\n## Troubleshooting\n\n### Issue: \"Supabase CLI not found\"\n\n```bash\n# Install Supabase CLI\nnpm install -g supabase\n\n# Verify\nsupabase --version\n```\n\n### Issue: \"Not logged in to Supabase\"\n\n```bash\n# Login\nsupabase login\n\n# This opens a browser for authentication\n```\n\n### Issue: \"Project not linked\"\n\n```bash\n# Link your project\nsupabase link --project-ref YOUR_PROJECT_REF\n\n# Find project ref at: https://supabase.com/dashboard/projects\n```\n\n### Issue: \"Function deployment fails\"\n\n```bash\n# Check for TypeScript/import errors\nsupabase functions deploy crb-check --verbose\n\n# View full error logs\nsupabase functions list --project-ref=<REF> --verbose\n```\n\n### Issue: \"Edge Function cannot access secrets\"\n\n1. Verify secrets are set:\n   ```bash\n   supabase secrets list\n   ```\n\n2. Check function code uses correct key names:\n   ```typescript\n   const key = Deno.env.get(\"CRB_API_KEY\"); // Must match exactly\n   ```\n\n3. Redeploy after changing secrets:\n   ```bash\n   supabase functions deploy crb-check\n   ```\n\n### Issue: \"Function returns 403 Forbidden\"\n\nThis likely means RBAC validation failed. Check:\n- User has admin/super_admin role in `user_roles` table\n- Auth token is valid and not expired\n- Bearer token format is correct: `Authorization: Bearer <token>`\n\n---\n\n## Next Steps\n\n1. ✅ Deploy Edge Functions\n2. ✅ Set environment variables\n3. ✅ Test from frontend (`SystemSettings.tsx`, `CompliancePayroll.tsx`)\n4. ✅ Monitor logs in Supabase Dashboard\n5. ✅ Merge PR to `main` branch\n6. ✅ Deploy to production\n\n---\n\n## Support\n\nFor issues or questions:\n\n- **Supabase Docs**: [https://supabase.com/docs/guides/functions](https://supabase.com/docs/guides/functions)\n- **Supabase Discord**: [https://discord.supabase.com](https://discord.supabase.com)\n- **GitHub Issues**: Create an issue in this repository\n\n---\n\n**Last Updated**: 2026-06-17\n"
